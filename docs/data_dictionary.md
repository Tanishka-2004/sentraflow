# SentraFlow Enterprise Data Dictionary & Classification Catalog

## 1. Entity Classification Schema

| Classification Tier | Sensitivity Description | Permitted Exposure | Cryptographic Transformation Rule |
|---|---|---|---|
| **PUBLIC** | Non-sensitive reference data | Unrestricted | None (Plaintext) |
| **INTERNAL** | Internal operational metrics | Authenticated internal users | None |
| **CONFIDENTIAL** | Financial account values & amounts | RBAC-authorized roles | Role-masked aggregates |
| **PII_DIRECT** | Directly identifies individual (PAN, Aadhaar, Phone, Email) | Strictly restricted to Gate | Deterministic HMAC-SHA256 / Format-preserving Hash / Redaction |
| **PII_QUASI** | Quasi-identifier (DOB, Pincode) | RBAC-authorized roles | Generalization (Age Band / 3-Digit Prefix) |

## 2. Customers (`silver.customers` & `dim_customer`)

| Column Name | Data Type | Classification | Masking Rule | Description |
|---|---|---|---|---|
| `customer_id` | STRING (UUID) | INTERNAL | None | Unique customer business identifier |
| `full_name` | STRING | PII_DIRECT | REDACT_INITIALS | Customer full legal name (`R*** V****`) |
| `pan_masked` | STRING | PII_DIRECT | MASK_PARTIAL | Permanent Account Number masked as `XXXXX1234X` |
| `aadhaar_token` | STRING | PII_DIRECT | TOKENIZE_HMAC | Deterministic HMAC-SHA256 token of synthetic 12-digit ID |
| `email_masked` | STRING | PII_DIRECT | HASH_EMAIL | Format-preserving salted hash (`h_ab12cd34@domain.com`) |
| `phone_masked` | STRING | PII_DIRECT | MASK_PHONE | E.164 phone with initial 6 digits redacted (`XXXXXX1234`) |
| `age_band` | STRING | PII_QUASI | GENERALIZE_AGE | Derived 5-year demographic age bracket (e.g., `25-29`) |
| `city` | STRING | INTERNAL | None | Customer residential city |
| `state_code` | STRING | INTERNAL | ISO_STANDARDIZE | Conformed 2-letter Indian state code (e.g., `MH`, `DL`) |
| `pincode_prefix` | STRING | PII_QUASI | TRUNCATE_PREFIX | First 3 digits of postal pincode (e.g., `400`) |
| `kyc_status` | STRING | INTERNAL | None | KYC verification level (`VERIFIED`, `PENDING`, `REJECTED`) |
| `valid_from` | TIMESTAMP | INTERNAL | None | SCD Type 2 dimension validity start timestamp |
| `valid_to` | TIMESTAMP | INTERNAL | None | SCD Type 2 dimension validity end timestamp (`NULL` if current) |
| `is_current` | BOOLEAN | INTERNAL | None | SCD Type 2 active record indicator |
